# Каталог компонентов

Отдельное приложение Storybook на React/Vite. Компоненты и стили импортируются
из `../ui/src`; основное приложение не импортирует Storybook. Каталог имеет
собственные зависимости и lockfile и не включается в Docker-образ агента.

## Запуск

Требуется Node.js 24 (минимум 22.12). Из корня репозитория:

```bash
cd storybook
npm ci
npm run dev
```

Адрес: http://localhost:6007. Порт 6006 оставлен Phoenix. Запуск агента,
Keycloak, PostgreSQL и Docker не требуется. Установка зависимостей `ui/` не требуется.

В разделе «Обзор» собраны основные элементы. Разделы «HITL» и «Экраны» содержат
сценарии компонентов, включая диалоги, формы и панели. В Controls доступны
переключатели состояния (`normal`, `empty`, `loading`, `error`) и подготовки ответа.
«Сбросить демоданные» или перезагрузка возвращает исходное состояние.

API заменён обработчиком в памяти: сообщения не отправляются агентам, настройки
и файлы не изменяются на сервере, демонстрационные токены недействительны.
Неизвестные маршруты возвращают ошибку без сетевого fallback. Файлы предпросмотра
и скачивания содержат только демонстрационный материал.

## Проверка и сборка

```bash
npm run typecheck
npm test
npm run build
```

Статическая сборка сохраняется в `storybook-static/`. Сценарии находятся в
`stories/`, конфигурация — в `.storybook/`. Добавление сценария не требует
изменения production-компонента или его API. Для новой серверной операции
следует добавить локальный ответ в `stories/demoData.ts`.

Каталог проверяет представление и взаимодействия UI, а не работу backend.
Основа конфигурации: [официальная документация Storybook для React/Vite](https://storybook.js.org/docs/get-started/frameworks/react-vite/).
