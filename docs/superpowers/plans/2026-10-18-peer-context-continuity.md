# Сохранение контекста исходящей A2A-переписки

Согласовано: context выбирает и передаёт harness; связь принадлежит локальному
чату и контрагенту. Локальный UUID не подменяет ID принимающего агента.

1. Зафиксировать LONG-06 и LONG-AC-06; сохранить чтение старых контрактов.
2. Registry: приватное поколение URL/авторизации, сохранение при metadata edits.
3. Scheduler: общая durable связь, сериализация Send, атомарная публикация ID,
   завершение очереди при неизвестном исходе, совместимый legacy bootstrap.
4. Runtime закрепляет trusted scope; executor передаёт context и сохраняет ID
   прямого Message. Public UI объясняет невозможность продолжить unknown context.
5. Проверить memory/PG, wire HTTP, restart/CAS/изоляцию; обновить spec lock,
   запустить targeted и полную unittest suite, Ruff, выполнить review и commit.

Не добавляются новый сервис, LLM-параметр contextId или автоматический повтор
неподтверждённых мутаций. Развёртывание в эту правку не входит.
